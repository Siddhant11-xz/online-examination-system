# Online Examination System

A Java Swing desktop application designed for conducting online multiple-choice examinations.

## Features
- Student login with name input and exam topic selection (Java Programming & General Knowledge)
- Interactive question navigation using Previous and Next buttons
- Automatic score calculation upon submission
- Complete answer review mode with color-coded feedback (Green for correct, Red for wrong)

## Technologies Used
- Java
- Swing / AWT (GUI)
